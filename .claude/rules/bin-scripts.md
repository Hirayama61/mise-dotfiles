# bin スクリプトの規約

- 直接実行するファイルだけが入口を持つ。
  `bin/lib/` の共有モジュールにはトップレベルの副作用を置かない。
- 入口関数は `main` ではなく `run` + 目的の名前にする(例: `runSymlink`)。
  起動は `if (import.meta.main)` で判定する。
- スクリプトの説明は、ファイル冒頭のコメントではなく入口関数の JSDoc に書く。
- ファイル内は import → 型 → 定数 → 純粋関数 → I/O を伴う関数 → 入口関数 → 起動判定の順に並べる。
- Bun に組み込み API がある処理は、npm 依存や自作より Bun API(`Bun.file`、`Bun.$` など)を使う。
