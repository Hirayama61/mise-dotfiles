`/polaris-review` スキルを実行し、その手順に従ってください。
1 回の実行で扱うのは PR 1 本だけです。承認か指摘を返し、マージ・push・コードの修正はしません。
PR の状態集め・検査の実行は、スキルが指定するサブエージェント (`collector` `checker` `explorer`) に任せてください。
最後に、扱った PR の番号、判定 (承認・指摘・CI 失敗の差し戻し)、指摘の要点、起票した Issue の番号を 5 行以内で報告してください。
