## 開発の流れ

- 思いつきと要望は polaris-data の `inbox/` に入る。クラウドの整理ループが分類し、明確なものだけをこのリポジトリ ({{REPO}}) の Issue にして `ready` ラベルを付ける。曖昧なものは Polaris のタスクとして質問が出る。
- クラウドの開発ループは `ready` の Issue だけを扱う。Issue 1 件につきブランチ `claude/issue-<番号>` と PR 1 本。CI (check) が通った PR を人がマージする。
- {{CHECK}} が通らない変更は出さない。

レビューと修正の基準は AGENTS.md にある。

## ラベル

| ラベル       | 意味                                      |
| ------------ | ----------------------------------------- |
| `ready`      | 整理済み。開発ループが実装してよい        |
| `needs-info` | 質問中。答えは Polaris の質問タスクに書く |
| `split`      | 小さな Issue に分割した元。閉じるのは人   |
| `hold`       | 人の判断待ち。ループは触らない            |
| `human`      | 人がやる Issue。ループは触らない          |

リポジトリ固有のラベルは残してよいが、ループは見ない。
