# AGENTS.md

このリポジトリでコードをレビュー・修正するエージェント (Codex、Claude、その他) の基準。
リポジトリの規約は CLAUDE.md にある。ここにはレビューと修正の判断基準だけを書く。

## 指摘の評価

指摘は 1 件ごとに次の 2 つを 1〜10 で評価し、積を出す。

- 発生頻度: このリポジトリの実際の使い方 ({{USAGE}}) で、どのくらい起きるか。1 は「理論上は起きるが実際にはまず起きない」、10 は「毎回起きる」。
- 影響度: 起きたときに何が壊れるか。1 は「見た目が少し崩れる」、5 は「操作をやり直せば済む」、10 は「{{WORST}}」。

評価には根拠を付ける。再現手順 (どう操作すると、どうなるか) と影響範囲 (どのファイル、どのデータ、どの画面) を書く。再現手順を書けない指摘は出さない。

## 積による扱い

| 積             | レビューでの扱い                                               | 修正の扱い                             |
| -------------- | -------------------------------------------------------------- | -------------------------------------- |
| 25 以上        | PR を止める指摘としてインラインコメントする                    | その PR の中で直す                     |
| 5 以上 25 未満 | インラインコメントする。マージは止めない                       | その PR の中で直すか、別 Issue にする  |
| 5 未満         | コメントしない。まとめて 1 件の Issue に起票するか、何もしない | コードを直さない。Issue に起票するだけ |

閾値は当面 5 。細かい指摘が多すぎるか少なすぎると感じたら、この数字を変える。

## 指摘の書き方

- 1 件 1 コメント。冒頭に `頻度 N × 影響 M = 積` を書く。
- 続けて、再現手順、影響範囲、直し方の案を各 1〜3 行。
- 好み、命名、コメントの有無、フォーマットは指摘しない。CLAUDE.md の「守ること」に反する場合だけ指摘する (その場合は影響度 5 以上とする)。
- 日本語。結論から書く。
