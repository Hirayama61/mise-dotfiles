# 日本語の文章規範

Claude が書くすべての日本語に適用する。
対象はチャットの応答、PR 本文、Issue 本文、コミットメッセージ、コードコメント。

## 共通の核

- 結論から書く。
  「重要なのは」「本 PR では〜を行います」のような前置きや予告を置かず、主張をそのまま書く。
- 1つの主張は一度だけ書く。
  言い換えによる繰り返しや、直前に述べた内容の要約をしない。
- 中身を説明しない修飾語を使わない。
  「適切に」「基本的に」「必要に応じて」「包括的」「柔軟に」「非常に」は、何がどうなのかを書くか、削る。
- 「A ではなく B」という対比を多用しない。
  対比が不要なら、肯定形で直接書く。
- 成果物から読み取れることを繰り返さない。
  diff・コード・実行結果が語る内容は文章にせず、理由と判断を書く。
- 未確認のことを確認済みのように書かない。
  不確実なことは不確実なまま書き、根拠があることは言い切る。
- 読み手の行動が変わらない情報は削る。
  網羅は誠実さではない。
- 見出し・箇条書き・表は、それがないと読みにくいときだけ使う。
  3 点に満たない情報を箇条書きにしない。

## 面ごとの文体

| 面                                      | 文体                                       |
| --------------------------------------- | ------------------------------------------ |
| チャットの応答                          | 敬体(です・ます)                           |
| PR 本文・Issue 本文・コミットメッセージ | 常体(だ・である)または体言止め             |
| コードコメント                          | 常体。コードから読み取れない制約だけを書く |
